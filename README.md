# Concurrencia_cpp

Programación Concurrente y RTOS

Repositorio enfocado en reforzar los fundamentos de la programación concurrente, los conceptos relacionados con los sistemas operativos y el funcionamiento de los sistemas de tiempo real.

Los conceptos estudiados serán posteriormente aplicados en sistemas embebidos utilizando una STM32F334R8 y un RTOS (Real-Time Operating System).

El objetivo es comprender primero los fundamentos teóricos de procesos, hilos, concurrencia, sincronización y planificación, para posteriormente trasladar estos conceptos al desarrollo de aplicaciones de tiempo real sobre un microcontrolador.
